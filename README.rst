``joyfl`` (pronounced *ˈjȯi-fəl*) is a dialect of the programming language Joy.

Joy is a stack-based programming environment that's both functional and concatenative, which results in highly expressive but short programs.  ``joyfl`` is an implementation of Joy in/for Python that's not entirely backwards compatible by design.
